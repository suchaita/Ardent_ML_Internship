# Customer Segmentation using K-Means Clustering

## 📌 Project Overview
This project demonstrates **customer segmentation** using the **K-Means clustering algorithm**, an **unsupervised machine learning** technique.

The goal is to group customers based on their **annual income** and **spending score**, helping businesses understand different customer types and make data-driven decisions.

This project is beginner-friendly and focuses on **visual understanding** of clustering.

---

## 📊 Dataset Description
A synthetic dataset is generated to simulate customer behavior:

- Feature 1: Annual Income
- Feature 2: Spending Score
- Each data point represents a customer

The dataset is created using NumPy to mimic real-world customer data.

## ⚙️ Implementation Steps

### 1️⃣ Import Required Libraries
Libraries for numerical operations, plotting, and clustering are imported.

### 2️⃣ Generate Customer Data
A synthetic dataset is created using random distributions to simulate:
- Low income – low spending customers
- Medium income – medium spending customers
- High income – high spending customers

---

---

### 3️⃣ Apply K-Means Clustering
The K-Means algorithm is used to:
- Group customers into clusters
- Identify cluster centroids
- Assign a cluster label to each customer

The number of clusters (`k`) is predefined based on the dataset.

---

### 4️⃣ Visualize Clusters
Matplotlib is used to visualize:
- Different customer clusters using distinct colors
- Cluster centroids using special markers

This helps in understanding how customers are grouped.

---

## 📈 Visualization Explanation
- Each point represents a customer
- Colors represent different clusters
- Centroids represent the “center” of each cluster
- The plot shows how customers with similar behavior are grouped together
